# Como aplicar a v0.8.1

Esta atualização é **consolidada**. Ela inclui os mapas e PDFs que faltaram no pacote incremental anterior.

1. Extraia o ZIP.
2. Abra a pasta extraída.
3. No GitHub, use **Add file > Upload files**.
4. Envie o conteúdo de dentro da pasta, preservando `public/`, `src/`, `docs/` e `package.json`.
5. Confirme a substituição dos arquivos existentes e faça o commit.
6. Aguarde a Netlify finalizar o deploy.

Depois do deploy, confira:
- Home com as duas coleções;
- capa brasileira de Hábitos Atômicos;
- seção Mapas na página de cada livro;
- botão Abrir mapa e Baixar PDF dentro de cada capítulo.
