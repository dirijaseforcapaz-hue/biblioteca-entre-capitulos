# Biblioteca Entre Capítulos v0.9.0

Esta atualização faz duas coisas juntas:

1. simplifica completamente a página inicial para deixá-la focada no catálogo;
2. inclui os assets físicos de Hábitos Atômicos que estavam faltando no GitHub.

## Como atualizar

Extraia este ZIP e envie TODO o conteúdo para a raiz do repositório `biblioteca-entre-capitulos`, mantendo as pastas e substituindo os arquivos existentes.

Depois do commit, confira no GitHub se existem:

- `public/images/books/habitos-atomicos.webp`
- `public/images/maps/habitos-atomicos/` com 20 arquivos `.webp`
- `public/downloads/mapas/habitos-atomicos/` com 20 arquivos `.pdf`

A Netlify deve iniciar um novo deploy automaticamente.

## Nova Home

A página inicial agora contém apenas:

1. hero institucional;
2. catálogo das coleções;
3. quatro mapas em destaque;
4. Entenda -> Revise -> Aprofunde.

Foram removidos da Home os contadores grandes, capítulos misturados, análises completas, manifesto destacado e o bloco "Escolha como explorar".
