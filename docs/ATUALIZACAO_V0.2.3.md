# Atualização v0.2.3 - logo, vídeo e novo mapa

Esta atualização mantém a arquitetura da v0.2.2 e altera apenas os elementos necessários para o capítulo piloto e a marca.

## O que mudou

1. O cabeçalho e o rodapé passam a usar o monograma real **EC** derivado da logo enviada pelo canal. A palavra **Podcast** não aparece na marca usada no site.
2. O capítulo **O Loop do Hábito** recebe o vídeo `https://youtu.be/EogHSuSDS_Q`.
3. O player do YouTube aparece automaticamente e também existe um botão para abrir o episódio diretamente no YouTube.
4. O mapa antigo é substituído pelo conceito visual em formato de jornada.
5. O site usa uma prévia WebP otimizada e oferece o PDF A4 completo para download.

## Como publicar

1. Extraia o pacote de atualização.
2. No GitHub, abra `biblioteca-entre-capitulos`.
3. Use **Add file > Upload files**.
4. Envie o conteúdo do pacote preservando as pastas.
5. Confirme a substituição dos arquivos existentes e faça o commit na branch `main`.
6. A Netlify deverá iniciar um novo deploy automaticamente.

## Depois do deploy, confira

- Logo EC no cabeçalho e no rodapé.
- Nenhuma palavra “Podcast” dentro da logo exibida.
- Player do episódio no capítulo 1.
- Botão “Assistir no YouTube”.
- Novo mapa visual.
- Botão “Baixar PDF”.
