# Biblioteca Entre Capítulos v0.8.1

Esta versão consolida três correções importantes:

1. **Capa brasileira de Hábitos Atômicos**
   - usa a capa da edição brasileira Alta Life enviada como referência;
   - capas passam a usar `object-fit: contain` para evitar cortes.

2. **Home orientada ao catálogo**
   - remove a lógica visual de uma única obra em destaque;
   - mostra todas as coleções com o mesmo peso;
   - exibe contadores dinâmicos de livros, capítulos, mapas e coleções completas;
   - mistura capítulos de diferentes livros;
   - inclui vitrine de mapas e análises completas.

3. **Mapas realmente disponíveis**
   - este pacote inclui fisicamente os 29 mapas atuais e seus 29 PDFs;
   - adiciona uma galeria de mapas dentro de cada página de livro;
   - mantém os botões de abrir mapa e baixar PDF nas páginas dos capítulos.

## Importante

A atualização v0.8.0 era incremental e não continha os arquivos físicos dos mapas. A v0.8.1 é deliberadamente mais completa para corrigir isso mesmo que a v0.7.0 não tenha sido enviada integralmente ao GitHub.
